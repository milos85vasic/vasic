Бір шындық көзі, барлық жерде айналанған — ондаған хост арасында федерацияланған Git.

Қысқаша мазмұны

HelixGitpx (Helix Git прокси кеңейтілген) — бір шындық көзін көптеген жоғары деңгейлі Git хосттары арасында айналып тұратын федерацияланған Git проксисі. Ол қажетті konflтктерді саясаттық және AI көмегімен ажырату ағымдарын қолдана отырып шешеді. Жоба v1.0.0 GA нұсқасына жетті.

Қысқаша сипаттама

HelixGitpx — бір шындық көзін ондаған Git хосттары арасында (GitHub, GitLab, Gitea, Bitbucket, Azure DevOps, AWS CodeCommit және басқалары) айналып тұратын федерацияланған Git проксисі. Ол синхрондау konflтктерін саясаттық және AI көмегімен ажырату ағымдары арқылы шешеді. v1.0.0 GA нұсқасы ретінде жеткізілді.

Кеңейтілген сипаттама

HelixGitpx — “Helix Git прокси кеңейтілген” — бір шындық көзін көптеген жоғары деңгейлі Git хосттары арасында айналып тұратын федерацияланған Git проксисі. Ол бір дерекқор бірнеше жерде орналасқан кезде туындайтын қақтығыстарды шешеді. Оның қолдау көрсететін жоғары деңгейлі хосттары Git экосистемасының толық картасын елестетеді: GitHub, GitLab, GitFlic, GitVerse, Gitea, Gitee, Bitbucket, Azure DevOps, AWS CodeCommit, Forgejo, SourceHut және жалпы Git-over-HTTPS. Наивті git push ондаған қашықтағы хосттарға жіберілгенде тіпті сәтсіз болуы немесе, одан да нашар, айналарды үнсіз түрде айырып жіберуі мүмкін. Ал HelixGitpx саясаттық және AI көмегімен ажырату ағымдарын қолдана отырып, айырмашылықтарды бір ғана беделді шындыққа келтіреді.

Жоба v1.0.0 GA нұсқасында, m1-foundation бастап m8-ga дейінгі кезеңдер белгіленген — негізден жалпы қолжетімділікке дейінгі толық жол. Ол үш деңгейлі бір өнім ретінде жасалған: федерациялық қозғалтқышты қамтитын Go монорепозиторий (платформа, он сегіз қызмет, код генерациясы және құрылымдық құралдар); Angular 19 + Nx веб-қосымшасы; және Kotlin-Multiplatform + Compose клиенттік қабықшалары, ортақ кодтан Android, iOS және десктопқа нативті тәжірибелерді жеткізеді. Платформаның жеткізілуі Kubernetes-ға толық сәйкес — Helm диаграммалары, Argo CD қосымшалары, Kustomize оверлейлері, SQL және OPA саясаттары — CI құбырлары анық диспетчерлеу арқылы бақыланады, ештеңе кездейсоқ шығарылмайды. Қоғамдық құжаттама Docusaurus сайты (docs.helixgitpx.io) ретінде, ал маркетингтік сайт Astro (helixgitpx.io) ретінде жеткізіледі.

Басқару қатаң және конституцияға негізделген, бұл рәсім емес, ерекшелік: жобаның негізгі құжаты — Constitution, оның II бабы жеті түрлі сынақ матрицасын әр түрлі өзгертілген модуль бойынша 100% қамтуды талап етеді, моктар тек бірлік сынақтарында рұқсат етіледі, ал өткізілмеген сынақ мүлдем жол берілмейді. Барлық артефакт тексеруін, go vet және go test жұмысын бүкіл жұмыс аймағында бір рет тексеріп шығатын бір реттік тексеруші жұмыс істейді, әрбір push барлық конфигурацияланған жоғары деңгейлі хосттарға таратылады — демек, “айналар синхрондалған” деген сөз жүйе әрбір коммитте қадағаланады, ал адамның есіне сақтауына мүмкіндік берілмейді.

Неліктен жасадық

Бір дерекқорды көптеген Git хосттары арасында нақты сақтау — артықшылық, егемендік немесе аймақтық платформаларға қол жеткізу үшін — әлсіз және қолмен істелетін процесс. Ал айырмашылықты айналарды келістіру қиын. HelixGitpx көп жоғары деңгейлі айналарды бірінші дәрежелі, конфлиттерді сезіну қабілеті бар мүмкіндік ретінде жасады.

Мәтін

Неге бұл ойынды өзгертетін шешім

Ол “көптеген қашықтағы репозиторийлерге итеріп, үміттену” деген нәзік, қолмен жасалатын әдісті бір орталықтан басқарылатын федерацияға айналдырады. Мұнда бір ғана ақиқат көзі және автоматтандырылған, саясат пен AI негізіндегі конфликтілерді шешу механизмі бар. Сонымен қатар, ол әдеттегі құралдардың елемеуіне қарамастан, аймақтық платформаларды (GitFlic, GitVerse, Gitee) әдейі қамтитын, кең ауқымды хосттар жиынтығын қамтиды. Нәтижесінде артықшылықтар, деректердің егемендігі және осы экосистемаларға кіру енді техникалық қиындық емес, бір рет конфигурациялау арқылы қол жеткізілетін мүмкіндікке айналады.

Инновациялық жақтары

  • Өзгерту көздерінің кең ауқымы — GitHub және GitLab сияқты оннан астам Git хосттарынан бастап GitFlic, GitVerse және Gitee сияқты аймақтық платформаларға дейін, барлығы бір прокси арқылы стандартталады.
  • Саясат пен AI көмегімен конфликтілерді шешу — айырмашылықтар саясаттық қозғалтқыш пен AI шешушісі арқылы келісіледі, қолмен айналарды салыстырудың қажеті жоқ.
  • Бір ақиқат көзіне негізделген федерация — барлық өзгерту көздеріне бір орталықталған итергіш модель, мұнда бір ғана репозиторий ақиқат көзі болып табылады, ал басқа хосттар оның айналары ретінде синхрондалады.
  • Қатаң, конституциялық тестілеу — әрбір түрде 100% қамтылымды жеті тест түрі, олардың дұрыстығы бір реттік green-suite скрипті арқылы дәлелденеді, ал сенімге негізделмейді.

Ең үлкен техникалық қиындықтар және оларды қалай шештік

  • Көптеген өзгерту көздеріндегі айырмашылықтар мен конфликтілер. Бір репозиторий ондаған жерде орналасқан кезде, екі хост әртүрлі өзгерістерді қабылдаған сәтте айырмашылықтар пайда болады. Бұл мәселе бір ақиқат көзіне негізделген саясат пен AI көмегімен шешілді, сонымен қатар барлық өзгерту көздеріне синхрондалған итергіш арқылы әрбір айна осы бір ақиқатқа сәйкестендіріледі.
  • Әртүрлі Git хосттарына біркелкі қолдау. Әрбір хосттың өз аутентификациясы, ерекшеліктері және API бар. Бұл мәселе Upstreams/ папкасындағы әрбір өзгерту көзіне арналған конфигурациялық скрипттер және платформалық деңгей арқылы шешілді, бұл айырмашылықтарды жасырады, сондықтан жаңа хостты қосу конфигурациялау арқылы жүзеге асырылады, кодты қайта жазудың қажеті жоқ.
  • Әрбір біріктіру алдында дұрыстығын дәлелдеу. Бұл мәселе міндетті жеті түрлі тест матрицасы және толық тексеру жиынтығын іске қосатын verify-everything.sh бір реттік қақпасы арқылы шешілді. Сонымен қатар, кластерге қосылу мүмкін болмаған жағдайда таза қысқа тұйықталу жүзеге асырылады, сондықтан дұрыстық жергілікті деңгейде де, CI ортасында да дәлелденеді.

Техникалық стек

  • Go монорепозиторий — негізгі прокси және федерациялық қозғалтқыш: платформа, 18 қызмет, кодты генерациялау және құрылымдық сүйемелдеу, барлығы бір репозиторийде сақталады, сондықтан бүкіл қозғалтқыш бір бірлік ретінде құрастырылып, тестіленеді.
  • Angular 19 + Nx — веб-қосымша, мұнда Nx үлкен алдыңғы бөлікке қажетті монорепозиторий құрылымы мен кешенді кешті қамтамасыз етеді.
  • Kotlin Multiplatform + Compose — Android, iOS және десктоп клиенттерінің бір кодтық базадан генерацияланған туындылары, сондықтан үш платформа үшін үш әртүрлі жүзеге асырудың қажеті жоқ.
  • Kubernetes + Helm + Argo CD + Kustomize — бұлттық жеткізу: Helm релизді пакеттейді, Kustomize әрбір ортаға бейімдеу үшін оверлейлерді қолданады, ал Argo CD GitOps арқылы кластердің күйін Git-ке сәйкестендіреді.
  • OPA (Rego) — конфликтілерді шешу және кіруді бақылау үшін код түріндегі саясат, бұл авторизациялық шешімдерді декларативті және тексерілетін етеді.
  • Docusaurus — қоғамдық құжаттама сайты (docs.helixgitpx.io); Astro — маркетингтік сайт (helixgitpx.io), әрбір құрал өз мазмұнына сәйкес таңдалған.
  • mise — әрбір қатысушы мен CI орындаушысы бірдей нұсқалармен жұмыс істейтін бекітілген, қайталанғыш құралдар тізбегі.
