As we already mentioned, in Kotlin we can make class fields abstract as well.
Depending on if these fields are val or var we must implement proper getter or
getter with a setter in class that is extending:
abstract class DbProvider {

abstract val database: String
}
class PostgresProvider : DbProvider() {

override val database: String

get() = "Postgres"

}
class MySQLProvider : DbProvider() {

override val database: String

get() = "MySQL"

}
