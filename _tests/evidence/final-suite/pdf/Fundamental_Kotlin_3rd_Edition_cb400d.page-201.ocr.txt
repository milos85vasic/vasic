As you can see we have created a list that contains only letters used in these
words. However, there is a lot of duplicates in the list which is annoying. To get
a rid of duplicates we will sort the list (because we want to have all letters
sorted in alphabetical order) and add all members into the set which will
remove our duplicates:
val letters = mutableSetOf<Char>()
val sortedLetters = mutableListOf<Char>()
letters.addAll(allLetters)
sortedLetters.addAli(letters)
sortedLetters.sort()
If we print out the content of the set:
printin(sortedLetters)
The following output will be produced:
lab¢dehilmnop,5s,t u,v, w]
Another more easy way to get rid of duplicates is to use “distinct” function:
val sortedLetters = allLetters.distinct().sorted()
Which will produce exactly the same results.
