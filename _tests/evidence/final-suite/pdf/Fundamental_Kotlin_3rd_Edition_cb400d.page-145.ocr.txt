Invoke
In Kotlin, all objects with an “invoke” operator defined can be invoked as a
function. Open “Invoke.kt” from book code examples:
class Invokable {

operator fun invoke(): Invokable {

printin("I am invoked")
return this

}
}
We have defined the “Invokable” Kotlin class that can be invoked as a function.
To invoke it, we have to create a new instance of the class and execute (invoke)
it:
val invoker = Invokable()
invoker()
Invoking our class instance will give us the following output:
Iam invoked
