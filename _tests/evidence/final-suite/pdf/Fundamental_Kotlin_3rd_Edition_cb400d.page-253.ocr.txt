“Run” scope function
With the “run” scope function the context object is available as a receiver. In this
case, it is available as a receiver via “this”. The return value of the “run” scope
function is the lambda result. “run” scope function behaves similar to the “with”
scope function. The main difference is that it invokes as “let” scope function, as
an extension function of the context object.
