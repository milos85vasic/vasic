}
}
Value is cast to String data type using “as” cast operator. Logger function
accepts any data type and performs explicit conversion to String data type. The
most upper type for all Kotlin classes is “Any”. Each Kotlin class inherits it. We
will talk soon about Kotlin classes and inheritance.
