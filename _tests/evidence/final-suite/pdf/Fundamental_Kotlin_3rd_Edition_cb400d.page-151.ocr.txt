This function is very similar to the one from the previous example with one
difference. We have one “fixed” additional parameter. We will again calculate
the sum and then multiply it with the value of the “multiply” argument:
val multiply = 100
sumAndMultiply(multiply)
sumAndMultiply(multiply, 1)
sumAndMultiply(multiply, 1, 2)
sumAndMultiply(multiply, 1, 2, 3)
sumAndMultiply(multiply, 1, 2, 3, 4)
