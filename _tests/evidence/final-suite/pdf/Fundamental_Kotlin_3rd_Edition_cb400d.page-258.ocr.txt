You will notice that each constant (“s1”, “s2”, and “s3”) has the same hash code
which means that it points to the same reference. Objects occupy memory as a
single instance which makes them a perfect candidate for singleton pattern
implementation.

Lazy initialization

Lazy initialization represents a delaying of instance creation, the calculation of a
value, or some other expensive process until the first time it is needed (access
to the variable for example).
