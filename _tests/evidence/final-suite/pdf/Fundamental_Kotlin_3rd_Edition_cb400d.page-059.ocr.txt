We introduced a function with an expression body and inferred return type.
In the same file we have a function that does not return a value, for that
purpose we use Unit type:
fun printSum(x: Int, y: Int): Unit {
printin("Sum is ${x + y}")
}
Since our function does not return anything, we can leave out the Unit return
type:
fun printSumSimplified(x: Int, y: Int) {
printin("Sum is ${x + y}")
}
