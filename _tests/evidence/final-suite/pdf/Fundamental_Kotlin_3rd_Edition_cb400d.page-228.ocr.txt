We have defined “enum” called “CAPABILITIES” with abstract function member:
“execute”. Because of this, each “enum” constant must implement it. Let's try it:
val capabilities = listOf(
CAPABILITIES.POWER_ON,
CAPABILITIES. VOLUME_UP,
CAPABILITIES. VOLUME_UP,
CAPABILITIES. VOLUME_DOWN,
CAPABILITIES. POWER_OFF
)
for (capability in capabilities) {
capability.execute()
}
Running this little “enums” program will produce the following output:
Powering on
Vol +
Vol +
Vol -
Powering off
