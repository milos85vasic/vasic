Strings in Kotlin
String data type represents a sequence of characters. In Kotlin, Strings are
immutable. Elements in one String are characters that can be accessed like any
other array.
Let's have a look at the “Strings.kt” source code file. We will start with defining
some simple strings:
val s1 = "Some string"
In this example, we have defined a constant named “s1” with the value of:
“Some string”.
Then, the next example is with the escaped character. In this example we are
escaping tab character:
val s2 = "Some\tstring\n"
Printing the value of “s2” gives the following output:
Some string
Kotlin supports the definition of multi-line strings too:
