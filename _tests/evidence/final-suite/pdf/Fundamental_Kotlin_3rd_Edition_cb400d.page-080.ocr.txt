The most important part of this example lies in the “Int?” part where we
defined our function return type. This means, the returned value type is an
integer but it may be also null. If we have defined our function return type as
“Int” instead of “Int?” we could not return null.
“Int?” type is “optional” type. Every class has its “optional” equivalent. Optional
is a container class used to contain null or non-null objects. The optional object
is used to represent null with an absent value. Thanks to facilities that are
exposed to the user's access to nullable data are safe and guarded.
