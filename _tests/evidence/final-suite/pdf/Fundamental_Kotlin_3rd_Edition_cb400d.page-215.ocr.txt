Obtaining access to referent is achieved via the “get” function. The function

Soft references
A soft reference object can be cleared by the Garbage Collector in response to a
a memory demand. When a Garbage Collector is called, it iterates over all
elements in the heap. GC keeps reference-type objects in a special type of
queue. GC determines which instances should be removed by removing objects
from that queue after all objects in the heap have been checked. It is
guaranteed to be cleared soft references to softly-reachable objects before a
JVM throws an OutOfMemoryError.
Because of this, the time when a soft reference gets cleared is not guaranteed
or the order in which a set of such references to different objects gets cleared.
