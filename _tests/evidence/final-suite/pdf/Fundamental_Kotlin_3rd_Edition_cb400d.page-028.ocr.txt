Kobalt

http://beust.com/kobalt/home/index.html

Kobalt is a build automation tool written in pure Kotlin. Kobalt is inspired by
Gradle and Maven's build automation tools. While takes some good ideas of
them Kobalt also provides some new powerful features on its own. As all
previously mentioned build automation tools it is licensed under Apache
License 2.0.
