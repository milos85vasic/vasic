Logical operators

Kotlin supports two main logic operators:

- “| |" known as “or” operator and

- “&&" known as “and” operator.

“Or” operator returns true Boolean if either of the Boolean expression is true,
while on the other hand “And” operator returns true if all Boolean expressions
are true.
