enum class COUNTRY(val capital: String) {
ITALY(Rome"),
SPAIN("Madrid"),
RUSSIA(""Moscow"),
SCOTLAND("Edinburgh")
}
We have defined two “enums”. The first enum “TIME” does not have any values
associated with its constants. On the other hand, our second example,
“COUNTRY” has the associated value.
This is how we could access them:
printin("Time unit: ${TIME. MILLISECOND}")
printin("Time unit: ${TIME.SECOND}")
printin("Time unit: ${TIME.MINUTE}")
printin(
"Country vs capital: ${COUNTRY.ITALY} ->
${COUNTRY.ITALY.capital}"
)
printin(
"Country vs capital: ${COUNTRY.SPAIN} ->
${COUNTRY.SPAIN. capital}"
)
printin(
"Country vs capital: ${COUNTRY.RUSSIA} ->
${COUNTRY.RUSSIA.capital}"
)
Executing this simple code snippet will produce us the following output:
Time unit: MILLISECOND
