29.Інжынер платформаў. Спецыяліст па SDK. Аўтар.
30.16+ гадоў распрацоўкі праграмнага забеспячэння для распрацоўшчыкаў у маштабах вытворчасці. SDK, якія абслугоўваюць мільёны ўстановак на Android, iOS, Web і Server — створаныя для карпаратыўных кліентаў, у тым ліку AWS, Google, Bosch і Leica Geosystems. Тэхнічны аўтар (кніга *«Fundamental Kotlin»*, 3-е выд.) і стваральнік адкрытага коду, які стаіць за 240+ рэпазіторыямі ў галіне кіравання праектамі, платформаў штучнага інтэлекту/LLM, аўтаматызацыі інфраструктуры і мабільных прылад. Спецыялізуецца на стварэнні стабільных, высокапрадукцыйных API і фрэймворкаў, на якіх будуюць іншыя інжынеры.
31.Асноўныя праекты з адкрытым зыходным кодам
32.Адбраныя з 240+ рэпазіторыяў пяці арганізацый — выбраныя за маштаб, тэхнічную глыбіню і рэальны ўплыў. Кожны з іх — вынік месяцаў цэленай інжынернай працы.
33.Альтэрнатыва JIRA з адкрытым зыходным кодам — карпаратыўнае кіраванне праектамі і задачамі з кліентамі для розных платформаў (Web, Desktop, Android, iOS). Створаная для каманд, якія патрабуюць высокай прадукцыйнасці без прывязкі да вендара.
34.Размеркаваная платформа распрацоўкі шматмадэльнага штучнага інтэлекту — каардынацыя інтэлектуальных агентаў на розных машынах для сумеснай генерацыі, агляду і рэфактарынгу коду ў маштабах.
35.Універсальны карпаратыўны інструмент для перакладу электронных кніг — любы фармат уваходу, любая моўная пара. REST + HTTP/3 API з рэальначасовым стрымінгам прагрэсу праз WebSocket. Падтрымка некалькіх бэкендаў LLM.
36.Сэрвіс ансамбля шматмадэльных агентаў — аркестроўка некалькіх моўных мадэляў праз адзіны інтэрфейс з інтэлектуальнай маршрутызацыяй, рэзервовым пераключэннем і агрэгацыяй вынікаў.
37.Уніфікаваная платформа інферэнцыі штучнага інтэлекту — хутчэйшае запусканне мадэляў у любым маштабе з прадказальнымі выдаткамі. Адзіны API для дэплойменту, маніторынгу і аркестроўкі на розных апаратных бэкендах.
38.Развітая сістэма кіравання мультыпратаколнымі медыя-рэсурсамі — аўтаматычна каталагізуе, выдаляе дублікаты і сінхранізуе калекцыі медыя з інтэлектуальным узбагачэннем метаданых праз розныя пратаколы.
39.Сістэматычная платформа бенчмаркінгу і верыфікацыі LLM — запуск стандартызаваных ацэнак на розных мадэлях, адсочванне рэгрэсій і генерацыя справаздач аб адпаведнасці для забеспячэння якасці штучнага інтэлекту.
40.Кросплатформавы інструмент аўтаматызаванага тэсціравання — запіс інтэрфейсу, параўнанне скрыншотаў і аркестроўка тэстаў на вэбе, дэсктопе і мабільных прыладах з адзінай канфігурацыі.
41.Дэкларатыўнае разгортванне поштавых сервераў — аўтаматызацыя праз JSON, якая за некалькі хвілін разгортвае поўнасцю наладжаную поштовую інфраструктуру на розных дыстрыбутывах АС.
42.Універсальны канвеер апрацоўкі URL — маршрутызацыя спасылак для апрацоўкі на аддаленых або лакальных канцавых кропках з трансфармацыяй і дастаўкай на аснове плагінаў.
43.Сэрвіс спампоўвання відэа Tube-services — кросплатформавы дадатак на Flutter для спампоўвання медыя з розных стрымінгавых платформаў з чыстым інтэрфейсам у стылі Material Design.
44.Агульныя абстракцыі і рэалізацыі для Android — паўторна выкарыстоўныя кампаненты, утыліты і шаблоны, вынятыя з прадукцыйнай працы над SDK для некалькіх карпарацый.
45.Дадатковыя праекты: GrabTube (відэа-даунлоадар на Flutter), Android-Toolkit, Asinka (Kotlin IPC), Herald (сістэма падзей на Go), Courses-Creator і многія іншыя ў розных галінах.
