// 摘要

我设计并构建将LLM转化为可靠产品的软件。

我主要使用 Go 工作，同时根据需求使用 Kotlin / Kotlin Multiplatform、TypeScript/React、Python、Swift 和 Shell。我的产出以舰队形式组织，而非零散的单一应用：大型产品应用坐落在数十个小型、解耦、独立测试的模块之上，所有模块共享作为 Git 子模块的工程宪章。

这意味着修复会在所有内容中传播，新产品可以从已验证的部件组装而成，每项宣传的功能都有证据产生的测试支撑。我的北极星是一条规则——功能只有在真实用户能够使用且捕获到证据证明时才算完成。此页从概览切换到各个项目；每个项目链接到其完整的产品页面。
