// резиме

Дизајнирам и градим софтвер који претвара LLM‑ове у поуздане производе.

Првенствено радим у Go, са Kotlin / Kotlin Multiplatform, TypeScript/React, Python, Swift и Shell у складу са захтевима посла. Моји резултати су организовани као флот, а не као гомила једнократних апликација: велики производни програми који стоје изнад десетина малих, одвојених, независно тестираних модула, сви наслеђују заједничку инжењерску Конституцију као Git подмодул.

То значи да се исправке шире преко свега, нови производи се састављају од проверених делова, а свака рекламирана могућност је поткрепљена тестом који производи доказе. Моја северна звезда је једно правило — функција је завршена само када је прави корисник у могућности да је користи и када постоје снимљени докази који то потврђују. Ова страница прелази са прегледа на појединачне пројекте; сваки повезује на пуну страницу производа.

HelixConstitution shipped

Универзална, наследна инжењерска књига правила, распоређена као Git подмодул преко флота од 140+ репозиторијума. Кодификује anti‑bluff gate‑ове за доказе, имунитет на лажне позитиве, безбедност података/хоста и правила покривености; пројекти могу их ојачати али никада не могу ослабити, а сваки управљачки gate је упарен са тестом мутације који доказује да сам gate функционише.
