// Übersicht

Eine Flotte, eine Disziplin

Eine Flotte: Große Produktanwendungen auf Basis von Dutzenden kleinen, entkoppelten, unabhängig getesteten Modulen — gesteuert von einer gemeinsamen Engineering-Constitution und verifiziert durch Anti-Bluff-QA. Die dominante Sprache ist Go, sowie Kotlin/KMP, TypeScript/React, Python, Swift und Shell an den passenden Stellen. Die einheitliche These lautet: Eine Funktion ist erst dann fertig, wenn ein realer Nutzer sie nutzen kann und es erfasste Beweise gibt, die dies belegen.
