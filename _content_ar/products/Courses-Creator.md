المحتوى

**من ماركداون إلى دورة فيديو احترافية — مُعزَّزة بتقنية AI، متعددة المنصات.**

## الملخص

Courses-Creator هي مجموعة أدوات تحول نصوص ماركداون إلى دورات فيديو احترافية مُعزَّزة بتقنية AI: إثراء المحتوى عبر مصادر متعددة لـ LLM (OpenAI/Anthropic/Ollama)، وتوليد TTS عالي الجودة وموسيقى خلفية، ومشغلات سطح المكتب والهواتف المحمولة والويب — كل ذلك يتم نشره عبر Docker مع مراقبة Prometheus/Grafana.

## وصف مختصر

تحول ماركداون إلى دورات فيديو جذابة. يعمل محرك المعالجة Go على إثراء المحتوى عبر عدة مقدمي خدمات LLM، وينتج التعليق الصوتي (Bark/SpeechT5 TTS) والموسيقى، ويوزعها على مشغلات Electron لسطح المكتب، وReact Native للهواتف المحمولة، وReact للويب، مع نشر كامل عبر Docker ومراقبة شاملة.

## وصف مفصل

إنتاج دورة فيديو يتطلب عادةً عمل استوديو صغير متكامل: كتابة النصوص، تسجيل التعليقات الصوتية، اختيار الموسيقى، المونتاج، الترميز، ثم بناء مشغلات لكل منصة قد يستخدمها المتعلمون. لكن Courses-Creator يضغط هذه السلسلة بأكملها إلى مدخل واحد — نص ماركداون — وأمر واحد. في قلب النظام يوجد معالج Go الذي يدير خط إنتاج كامل للفيديو والصوت: فهو يُثري المحتوى المكتوب عبر عدة مقدمي خدمات LLM (OpenAI، Anthropic، وOllama المحلي)، وينتج تعليقات صوتية طبيعية باستخدام محركات تحويل النص إلى كلام (Bark، SpeechT5)، ويضيف طبقات من الموسيقى الخلفية، ثم يجمع كل القطع في فيديوهات جاهزة للدورة. يبقى دور المؤلف مقتصراً على الأفكار والكلمات، بينما يتولى النظام الصوت والتأليف الموسيقي والإنتاج. ولأن الدورة لا فائدة منها إذا لم يتمكن الناس من مشاهدتها، فقد تم تصميم التوزيع ليكون متعدد المنصات: تطبيق Electron لإنشاء الدورات على سطح المكتب، ومشغل React Native للهواتف المحمولة، ومشغل React للويب، وكلها تغذيها نفس البنية الخلفية REST API ونظام المهام الخلفية — بنية خلفية واحدة، وثلاثة عملاء متميزين، دون الحاجة لإعادة التنفيذ لكل منصة.

الأهم من ذلك، أن هذا النظام هو بنية إنتاجية حقيقية، وليس مجرد عرض تجريبي. تتضمن البنية الخلفية تخزين PostgreSQL، ومعالجة المهام الخلفية بحيث لا تعيق عمليات توليد TTS/الفيديو سير عمل API، وتنفيذ خوادم MCP لتعزيز المحتوى باستخدام الأدوات، ومقاييس Prometheus، ومصادقة JWT، وخادم وكيل عكسي nginx — وكل ذلك يتم نشره عبر حزمة Docker Compose مع ملفات مراقبة Grafana/Prometheus يمكن تشغيلها بخطوة واحدة. تقنية AI هي طبقة تعزيز اختيارية، وليست اعتماداً أساسياً: فكل مقدم خدمة LLM اختياري، مما يسمح للنظام بالعمل دون مفاتيح API في الوضع الأساسي، ويبدأ في إثراء المحتوى المتميز بمجرد توفير المفاتيح. هذا القرار الواحد يجعل الأداة نفسها صالحة للاستخدام من قبل الهواة الذين يعملون دون اتصال على حاسوب محمول، أو من قبل المؤسسات التي تدمج مقدم الخدمة المفضل لديها — وكل خط الإنتاج الإعلامي مدعوم باختبارات الوحدة والتكامل والنهاية إلى النهاية بدلاً من الاعتماد على الثقة العمياء.

## لماذا قمنا ببنائه

إنتاج دورات الفيديو يدوياً عملية بطيئة: الكتابة، والتعليق الصوتي، والتأليف الموسيقي، والمونتاج، كلها تتطلب جهداً وأدوات متخصصة. Courses-Creator يضغط هذه العملية في خط إنتاج مدفوع بماركداون، بحيث يتحول النص المصدر الواحد إلى دورة جاهزة، مع تقنية AI التي تملأ الفجوات التي كان سيضطر البشر لسدها يدوياً.

## لماذا يُعدّ هذا ثورةً في المجال

يحوّل إنتاج الدورات التعليمية من حرفة متخصصة تعتمد على أدوات متعددة إلى خط إنتاج برمجي قابل للتكرار: التأليف، AI الإثراء، توليد السرد والموسيقى، وتشغيل متعدد المنصات، كلها تتكامل في حزمة واحدة قابلة للنشر. أما التدهور الرشيق في حال غياب مفتاح API فهو القوة الصامتة للنظام — إذ يخدم نفس قاعدة الشفرة صانع المحتوى الفردي ذو الميزانية المحدودة والمؤسسة المتعاقدة مع مزود خدمات متميز، دون الحاجة لإعادة كتابة أي شيء بينهما.

## ما الجديد؟

- خط إنتاج من ماركداون إلى فيديو مع إثراء متعدد LLM قابل للتوصيل (OpenAI/Anthropic/Ollama).
- توليد TTS مدمج (Bark، SpeechT5) وموسيقى خلفية.
- تطبيقات خوادم MCP مدمجة داخل محرك المعالجة لتعزيز الأدوات.
- خلفية واحدة تخدم ثلاثة عملاء رئيسيين (Electron سطح المكتب، React Native الجوال، React الويب).

## التحديات والحلول

- **معالجة الوسائط الثقيلة:** تم حلها عبر خط إنتاج Go ومعالجة الوظائف الخلفية بحيث لا تعيق الوظائف الطويلة TTS/الفيديو مفتاح API.
- **AI اختياري لكنه قوي:** تم حله بجعل مزودي LLM اختياريين وقابلين للتوصيل، مع الرجوع الرشيق إلى الوظائف الأساسية.
- **التسليم متعدد المنصات:** تم حله عبر API مشترك REST وثلاثة تطبيقات تشغيل مخصصة.
- **قابلية التشغيل:** تم حلها عبر ملفات Docker Compose، Prometheus/Grafana، ومصادقة JWT مدمجة.

## مجموعة التقنيات (السبب + الكيفية)

- **Go** — محرك المعالجة الأساسي، API المشترك REST، مشغل الوظائف، خط الإنتاج (972 ألف بايت، اللغة المسيطرة).
- **TypeScript / React** — مشغل الويب وواجهة المستخدم المشتركة.
- **Electron** — تطبيق سطح المكتب للمبدعين.
- **React Native** — مشغل الجوال.
- **PostgreSQL** — تخزين الدورات والوظائف.
- **مزودو LLM (OpenAI، Anthropic، Ollama)** — تعزيز المحتوى.
- **TTS (Bark، SpeechT5)** — توليف السرد.
- **خوادم MCP** — دمج الأدوات داخل المحرك.
- **Docker Compose + nginx** — نشر كامل الحزمة وخادم الوكيل العكسي.
- **Prometheus + Grafana** — المراقبة.
