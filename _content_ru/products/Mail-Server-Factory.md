**Настройте свой почтовый сервер как профессионал — опишите его в JSON и разверните где угодно.**

## Краткое описание

Mail Server Factory — готовый к промышленной эксплуатации инструмент автоматизированного развёртывания почтовых серверов. Пользователь создаёт простой конфигурационный файл JSON, а Фабрика интерпретирует его и выполняет все установки и инициализации на целевой ОС, развёртывая почтовый стек на базе Docker с гибкой архитектурой из 12 типов подключений.

## Краткая характеристика

Инструмент Kotlin/Shell, преобразующий описание в формате JSON в полностью установленный и контейнеризированный почтовый сервер. Поддерживает 12 типов подключений (SSH, Docker, Kubernetes, AWS SSM, Azure, GCP, Libvirt и другие), полноценную систему безопасности, 25 дистрибутивов Linux и поставляется с 439 успешно пройденными тестами.

## Подробное описание

Развёртывание настоящего защищённого почтового сервера — один из классических ритуалов посвящения в системное администрирование и одновременно один из самых надёжных способов испортить себе настроение. Postfix, Dovecot, сертификаты TLS, записи DNS, правила брандмауэра и особенности каждого дистрибутива — всё должно быть настроено идеально, и одна неверная директива может обернуться молчаливым отказом в доставке писем или открытым релеем. Mail Server Factory берёт на себя весь этот накопленный годами опыт, подверженный ошибкам, и воплощает его в программном обеспечении. Вместо того чтобы вручную настраивать каждый компонент на незнакомой ОС, конечный пользователь описывает желаемый результат в простом документе JSON, а Фабрика считывает его и выполняет все необходимые шаги по установке и инициализации на целевой операционной системе, развёртывая почтовый стек на базе Docker, где каждый компонент слабо связан с другими. Такой подход обеспечивает горизонтальную масштабируемость и позволяет обновлять или заменять любой компонент изолированно. При этом инструмент намеренно не привязан к конкретной инфраструктуре: 12 типов подключений позволяют использовать один и тот же инструмент и один и тот же файл JSON для локальной машины, удалённого хоста по SSH, среды выполнения Docker или Kubernetes, облачных инстансов через AWS SSM / Azure Serial Console / GCP OS Login или виртуальных машин через Libvirt — одно декларативное описание, развёрнутое там, куда вы его направите. Поддерживаются 25 дистрибутивов Linux из западных (Ubuntu, Debian, CentOS, Fedora, AlmaLinux, Rocky, openSUSE), российских (ALT, Astra, ROSA) и китайских (openEuler, openKylin, Deepin) семейств с автоматической установкой через preseed/kickstart/cloud-init/autoyast и автоматизацией виртуальных машин на базе QEMU для тестирования. Корпоративные функции включают: шифрование AES-256-GCM, обязательные политики паролей и ключей SSH, автоматическую настройку брандмауэра для почтовых портов (25/587/465/993/995), поддержку TLS/SSL с проверкой сертификатов и HSTS, аудитное логирование и управление доступом на основе ролей (RBAC). В числе эксплуатационных возможностей: настройка JVM (G1GC), кэширование Caffeine, пул соединений, совместимые с Prometheus метрики, структурированное логирование, горячая перезагрузка конфигурации и управление секретами. Проект насчитывает 439 тестов с 100%-ным прохождением и чистый контроль качества SonarQube. Это флагманский продукт организации Server-Factory.

## Зачем мы его создали

Настройка защищённого почтового сервера для продакшена — задача, печально известная своей подверженностью ошибкам и зависимостью от операционной системы. Mail Server Factory воплощает этот опыт в декларативной модели JSON и исполнительном движке, позволяя воспроизводить корректный, защищённый и контейнеризованный почтовый стек на любой поддерживаемой платформе без ручной пошаговой работы.

## Почему это меняет правила игры

Решение превращает развёртывание почтового сервера из специализированной, многочасовой и требующей филигранной точности процедуры в акт написания конфигурации — причём эта конфигурация становится переносимой между 12 типами подключений и 25 дистрибутивами Linux, а также изначально защищённой благодаря корпоративным стандартам безопасности. Результат воспроизводим и *верифицируем*: одна и та же модель JSON каждый раз даёт один и тот же защищённый стек, а 439 успешно пройденных тестов и чистый SonarQube-гейт проекта означают, что движок, выполняющий работу, сам подотчётен, а не полагается на репутацию.

## Что здесь нового

- Декларативная модель JSON → интерпретируемая установка/инициализация на целевой ОС.
- 12 типов подключений (локальное, SSH, Docker, Kubernetes, AWS SSM, Azure, GCP, Libvirt и другие) в рамках одного инструмента.
- Поддержка 25 дистрибутивов с автоматической установкой (preseed/kickstart/cloud-init/autoyast) и QEMU-автоматизацией.
- Развязанный контейнеризованный стек для независимого масштабирования и обновлений.

## Проблемы и их решения

- **Разнородность ОС и дистрибутивов:** решено с помощью рецептов для каждого дистрибутива, конфигураций автоматической установки и QEMU-тестирования на кросс-платформенной основе.
- **Развёртывание на множестве целевых платформ:** решено за счёт 12 подключаемых типов соединений под единым движком установки.
- **Безопасность по умолчанию:** решено с помощью AES-256-GCM, обязательных политик ключей и паролей, автоматических правил межсетевого экрана и TLS/HSTS.
- **Доверие к корректности:** решено благодаря набору из 439 тестов (100% успешных) и чистому SonarQube-гейту.

## Технический стек (зачем и как)

- **Kotlin** — движок Factory и логика шагов установки (179 Кбайт; Kotlin 2.0.21).
- **Shell** — скрипты развёртывания, менеджеры ISO/QEMU и автоматизация ОС (занимает основной объём).
- **Docker** — среда исполнения для развёрнутого, развязанного почтового стека.
- **QEMU** — автоматизация виртуальных машин для кросс-дистрибутивной установки и тестирования.
- **JSON** — декларативный формат конфигурации, с которым работает пользователь.
- **Gradle 8.14.3 / Java 17** — инструментарий сборки.
- **Caffeine** — кэширование в нескольких регионах; **JVM с настройкой G1GC** для повышения производительности.
- **Метрики, совместимые с Prometheus** — мониторинг; готово к интеграции с Grafana/ELK.
- **Sieve** — правила фильтрации почты (занимает небольшую долю в статистике языков).
