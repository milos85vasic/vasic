# Miloš Vasić

## Герой

**AI-инженер, создающий верифицируемые системы разработки AI.**

Я строю ту часть AI-инженерии, которая отделяет надёжный продукт от впечатляющей демонстрации: мультипровайдерную инфраструктуру LLM, способную пережить отказ провайдера; автономные агенты и оркестрацию, удерживающие работу в нужном русле; а также уровни управления и контроля качества, не позволяющие системе AI незаметно вводить в заблуждение относительно своих возможностей. Превращение большой языковой модели в продукт, который можно реально поставлять, — это в первую очередь вопрос дисциплины, и именно этой дисциплиной я и занимаюсь. Мой путеводный принцип — одно простое правило: функция считается завершённой только тогда, когда её может использовать реальный пользователь и когда существуют зафиксированные доказательства её работоспособности.

## Обзор

Я работаю преимущественно в области **Go**, используя **Kotlin / Kotlin Multiplatform**, **TypeScript/React**, **Python**, **Swift** и **Shell** по мере необходимости. Для меня важнее всего то, *как* организована работа: не набор разрозненных приложений, а целое семейство — крупные продуктовые решения, опирающиеся на десятки небольших, независимых, автономно протестированных модулей, каждый из которых наследует общую инженерную **Constitution** в виде Git-сабмодуля. Именно этот архитектурный выбор позволяет всей системе развиваться по принципу сложного процента: исправления и улучшения распространяются на всё сразу, новые продукты собираются из уже проверенных компонентов, а каждая заявленная возможность подкреплена тестом, генерирующим доказательства, а не просто обещаниями. Это инженерия, созданная для того, чтобы ей мог доверять один человек — и масштабироваться она может до любого уровня. На этой странице я перехожу от общего обзора к отдельным проектам; каждый из них ведёт на полную страницу продукта.

## Как я работаю — управление и контроль качества на первом месте

Прежде чем говорить о продуктах, о дисциплине, которая их поддерживает:

- **HelixConstitution** — я поддерживаю универсальный, наследуемый свод инженерных правил, распространяемый в виде Git-сабмодуля на флотилию из более чем 140 репозиториев. Он кодифицирует защитные механизмы от обмана, устойчивость к ложноположительным срабатываниям, безопасность данных и хостов, а также правила покрытия; проекты могут ужесточать требования, но не ослаблять их, и каждый контрольный пункт сопровождается мутационным тестом, доказывающим его работоспособность. → см. страницу продукта HelixConstitution.
- **HelixQA** — я создаю систему антиобманного контроля качества, которая запускает банки письменных тестов и полностью автономные сессии QA с использованием LLM и компьютерного зрения на платформах Android, Android TV, Web и Desktop, засчитывая прохождение только при наличии зафиксированных доказательств выполнения. → см. страницу продукта HelixQA.

## Мои проекты в семействе Helix

Линейка Helix охватывает весь жизненный цикл разработки AI. В порядке приоритета:

- **HelixTrack** — альтернатива JIRA для свободного мира; флагман линейки Helix-Track.
- **HelixAgent** — ансамблевый сервис LLM с многораундовыми дебатами моделей и выбором провайдера на основе верификации.
- **HelixCode** — распределённая платформа разработки AI, распределяющая задачи между воркерами под управлением SSH с автоматическим созданием контрольных точек и откатом.
- **HelixLLM** — единый бинарный файл с шестью режимами работы, предоставляющий совместимые с OpenAI и Anthropic API через HTTP/3, с локальным выводом через llama.cpp и цепочкой откатов с оценкой качества.
- **HelixCluster** — распределённая операционная система для вычислений на базе AI — от датацентровских GPU до периферийных портативных устройств.
- **LLMProvider** — единый интерфейс для 43 провайдеров с встроенными предохранителями, повторными попытками и мониторингом работоспособности.
- **LLMOrchestrator** — единая панель управления для всех бесголовых агентов кодирования CLI.
- **LLMsVerifier** — проверяй, наблюдай, оптимизируй: единый источник истины для метаданных LLM, провайдеров и верификации.
- **HelixMemory, HelixSkills, HelixSpecifier, HelixBuilder, HelixTranslate, HelixTerminator, HelixGitpx, HelixOTA, HelixPlay** — память агентов, управляемые навыки агентов, разработка на основе спецификаций, создание приложений AI, верифицированный перевод книг, терминалы с нулевым доверием, федеративный Git, безрисковые обновления OTA и облачный гейминг с самохостингом.


## Мои разработки в области vasic-digital utils

Инструменты промышленного уровня, которые я создал и поддерживаю (у каждого есть полноценная страница продукта):

- **Catalogizer** — мультипротокольный (SMB/FTP/NFS/WebDAV/локальный), зашифрованный, саморазвёртываемый менеджер медиаколлекций с Go/Gin API и React интерфейсом.
- **Courses-Creator** — конвейер преобразования markdown в видео с мульти-LLM обогащением, TTS и плеерами для десктопа, мобильных устройств и веба.
- **VisionEngine** — децентрализованный Go-тулкит, сочетающий классическое компьютерное зрение с мультипровайдерским LLM-зрением для анализа интерфейсов и построения графов навигации.
- **DocProcessor** — превращает документацию в верифицируемую карту функций для автоматизации QA (LLM или эвристическая экстракция).
- **Docs Chain** — контент-хешированный, двунаправленный, атомарный движок синхронизации документов и баз данных.
- **Herald** — надёжные мультиканальные уведомления с разрешением интентов на трёх уровнях на естественном языке.
- **task_bridge** — децентрализованный, двунаправленный движок синхронизации задач и досок (P1-каркас; логика синхронизации в разработке).
- **Набор переиспользуемых модулей Vasic Digital** — «стандартная библиотека» `digital.vasic.*` из инфраструктурных, AI-примитивных модулей и модулей-ограничителей.
