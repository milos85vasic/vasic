`upstreams/GitHub.sh` push recipe) had no registry row, so the unregistered-scripts class could not tell a
deliberate exclusion from an oversight, and the deferral carried no recheck date.

## Alternatives considered

1. Declare `_tests` a scanroot: rejected in the registry comment, `_tests/` also holds evidence output written under
   concurrent edit, so a recursive sweep would produce unstable findings.
2. Register each script individually (chosen): proofs and generators get `exempt` rows with a reason, an owner and
   a recheck date; the aggregator is a real `check` row with a paired proof.
3. Leave the deferral: leaves two undated, unexplained exclusions.

## Why the fix is right

The probe runs the real class and fails if any of the seven paths reappears as a FINDING, and it requires the
aggregator's own `--prove-failure` to pass, so a row cannot be added without its paired proof. Residual limit: exempt
rows are judgments recorded with a recheck date, not proofs that the script is harmless.
