# VSC-373: research note (section 11.4.150)

Author: fixer of record `closer-fixer-b5` (re-closure batch 5). Check author per controller attestation 2026-10-12:
`t047-gd-dd-fixer-1`. No web search or fetch was performed; every source below is a path in this repository that was read.

## Defect class

Blind spot in a sweep: the registry's unregistered-script rule (R5) enumerated each plain `scanroot` with
`find -maxdepth 1`, so shell scripts in subdirectories of `_tools/` were never seen. A hand-written list of the missed
scripts in the registry header had itself drifted (it read six, was corrected to seven, and nine existed).

## Sources consulted

- The item record in `docs/workable_items.db`.
- `scripts/verify-check-registry.sh` (the `recursive` scanroot flag) and `scripts/check-registry.tsv` (`scanroot _tools recursive`,
  nine new `exempt` rows each with a reason read from the script's own header, the hand list removed in favour of a derive command).
- `docs/zero-gap/guard-waivers.tsv` (nine `add-exempt` waivers) and `scripts/zero-gap-guard-checks.sh` (waiver rules).
- `docs/zero-gap/checks/VSC-373.check` and `VSC-373.probe.sh`.

## Alternatives considered

1. Extend the hand-written list: it already drifted twice.
2. Declare every subdirectory as its own plain scanroot: same drift risk, one row per directory.
3. A `recursive` flag on the existing scanroot (chosen): a directory added later is covered with no edit.

## Why the fix is right

The probe enumerates every tracked or untracked `*.sh` below `_tools/` and requires each to be registered or inside a swept
root, then runs the meta-check and requires no UNREGISTERED line. Guard check on a simulated commit (scratch repository:
base = HEAD content, head = working tree): `zero-gap-guard-checks.sh` reported HOLDS with every added exempt row WAIVED; all nine
waivers name `check-registry`, a check row that carries `--prove-failure` and whose entry point exists. Residual limit: the guard
does not see uncommitted changes, so this was exercised on a scratch commit, not on the real push.
