Under this sweep rc=2 scores ERROR (§11.4.201(7)(b)), never PASS, so the comment misdescribed both the exit code and the hazard it was warning about. §11.4.6 forbids leaving a verified-false statement in place. #   2. Else if it offers a `selfcheck)` subcommand    -> run `selfcheck <tmpdir>`.

All 21 were reproduced by hand, with the argv each gate’s own usage header dictates. Every failing assertion is a true statement about the tree. Two false-verdict hazards exist but the sweep avoids both:
