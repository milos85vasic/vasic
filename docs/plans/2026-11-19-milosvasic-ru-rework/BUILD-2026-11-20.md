## Design system v2 — "Aurora Atlas"

- **OKLCH tokens** for accent + neutrals, with hex fallbacks written as the
  variable's second declaration (`--a2-accent: #7c5cff; --a2-accent: oklch(59.90% 0.230 286.2);`
  — legacy browsers drop the second, modern ones take the last). Usage sites read
  `var(--a2-accent, #a31e39)`; `--a2-accent-muted`, `--a2-focus-ring` and the
  per-area `--a2-accent-on` (fg on accent) are derived via `color-mix` where
  supported. Values were computed from the recipe accents (e.g. `#3ddc84` →
  `oklch(79.30% 0.180 154.0)`) with a real hex→oklch conversion.
- **Per-area accent** via `[data-area="<slug>"]` (set on the hub tiles and on
  `<main data-area>` on area pages) — 10 distinct OKLCH accents; `--a2-accent-on`
  per area was chosen by actual contrast against white vs `#111217`.
- **`@view-transition { navigation: auto; }`** — cross-document transitions;
  `prefers-reduced-motion: reduce` → `navigation: none`.
- **Scroll-driven animations** (progressive enhancement, `@supports
  (animation-timeline: view())`): `.a2-intro` (hub hero) fades/drifts on
  `animation-timeline: view()`; `.a2-timeline` (area-page timeline section)
  fades in on `animation-timeline: scroll(block)`; both disabled when
  `prefers-reduced-motion: reduce`.
- **WCAG 2.2 AA**: `html { scroll-padding-top: calc(64px + .75rem); }`
  (focus-not-obscured under the sticky 64px nav); focus targets on the tiles /
  area back-link / project links are ≥24px (`.mv-expertise-tile` min-height
  6.25rem, min-width 13rem) with visible focus rings
  (`border: 2px solid var(--a2-accent)` + `box-shadow: 0 0 0 3px var(--a2-focus-ring)`).
- **`[dir="rtl"]`**: mirrored tiles/container, timeline line + year alignment,
  `mv-area-back` arrow content, text alignment on the hub/area copy.
- **Grid layouts + backdrop-blur cards**: `.mv-expertise-tiles`,
  `.mv-area-header`, `.mv-area-project-blurbs`, tiles and the area header carry
  `backdrop-filter: blur(...)`.

## Hub page (`/expertise/`)

10 tiles, each with: index (01–10), accent (`data-area`), title, HeroMetric
(first metric from `resolve()` — e.g. `43 LLM providers behind one interface`),
tagline (recipe), top-3 projects (from `resolve()`), and a link to
`/expertise/<area>/`.

JSON-LD: `ProfilePage` → `mainEntity: Person` with `jobTitle`, `knowsAbout`
(the 10 area titles), `hasOccupation` ×10 (`Occupation` with `mainEntityOfPage`
→ each area page), `worksFor` (Organization).

## Area pages (`/expertise/<area>/`)

CV/CL context rendered from the career engine (`_tools/career/resolve.py`,
`kind="cv"` and `kind="cover"`): experience (company, role, period, location,
summary, bullets, tech — reverse-chronological), projects (6, with tier + tech +
blurb leads), metrics, competencies, skills, education, publications, languages,
plus the cover-letter context (opening, angle, cover paragraphs).
Hand-written narrative per area (story + 3 project blurbs) — the area tagline
and cover-letter angle come from the recipe (`area.tagline`,
`cover_letter.angle`).

JSON-LD: `ProfilePage` → `mainEntity: Person` with `jobTitle` (the area title),
`knowsAbout` (area keywords), `hasOccupation` (the area, with
`mainEntityOfPage` pointing back at the page).
