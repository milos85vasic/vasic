1. How to read this record

  • Wording. The operator’s own typed words are not visible to the agent that wrote this record. Each decision below is paraphrased from the brief unless a row says it quotes a file. No quotation has been invented.
  • Who decided. Operator means the operator personally. Delegate means the orchestrating agent acting under the standing approval (OR-02 of the 2026-10-20 record); a delegate decision is amendable by the operator. Section 3 is a delegate waiver, not an operator decision, and is kept apart from the decisions for that reason.
  • Status vocabulary. DECIDED (operator), RATIFIED (an earlier delegate default the operator has now confirmed), DEFERRED (the operator put it off), APPROVED-NOT-EXECUTED (the operator approved an action that had not been carried out when this was written), OPEN (investigation or decision continues), IN EFFECT (a standing rule).
  • Verification. “Checked” means the cited file or git object was read by the author of this record on 2026-10-21. “Brief” means the statement comes from the brief only and was not re-read from a repository file or the live stack; the live-stack facts of this day (restarts, embedding totals, the state of the live registry) are all brief-only here: UNCONFIRMED by this record.
