Recorded in full, because a mis-specified guard is more dangerous than a missing one — it teaches the next agent to stop on a safe operation and, worse, implies the unsafe one is covered.

MY RULE (wrong):      STOP if root_hash moves — "you have broken citations"
CORRECTED RULE:       STOP if any EXISTING pid or content_hash CHANGES

root_hash moving is the NORMAL signature of any append. As written, my rule would have blocked every legitimate ingest while catching nothing that a mutating re-cut does differently. The evidence that this move was additive:
