1. How to read this record, and its limits

  • Wording. The operator’s own typed words for this session are not visible to the agent that wrote this record. Every entry below is therefore marked paraphrased (taken from the task brief that the orchestrator relayed, and from the spec files) unless it says verbatim from a file, in which case the quoted text is in the cited file. No quotation has been invented.
  • Who decided. “Operator” means the operator personally. “Delegate” means the orchestrating agent acting for the operator under the standing approval; a delegate decision is amendable by the operator and is marked as such. This distinction is kept because spec 026 itself makes it (O-1 is “RESOLVED … by the operator’s delegate (not an operator-typed decision; the operator may amend)”).
  • Status vocabulary. DECIDED (operator), DELEGATE-DEFAULT, UNRATIFIED (a default taken by the delegate and implemented; the operator has not ratified it and the repository record may still list the question as open), ACCEPTED (not contested, per the cited source), IN EFFECT (a standing rule), OPEN (not decided; the default shown is what is being implemented). A row says which file shows the status; where the files and the brief disagree, both are named and the repository file is the record.
  • Content boundary. This is a public repository. Textbooks and recordings are named by path or count only. No title, no text and no credential appears here.
