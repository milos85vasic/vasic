محتوا

**از مارک‌داون به دوره ویدیویی حرفه‌ای — ارتقایافته با AI، چندسکویی**

## خلاصه

Courses-Creator جعبه‌ابزاری است که اسکریپت‌های مارک‌داون را به دوره‌های ویدیویی حرفه‌ای با ارتقاهای مبتنی بر AI تبدیل می‌کند: غنی‌سازی چندجانبه محتوا (OpenAI/Anthropic/Ollama)، صدای باکیفیت TTS و موسیقی پس‌زمینه، و پخش‌کننده‌های دسکتاپ، موبایل و وب — همه با استقرار Docker و نظارت Prometheus/Grafana.

## توضیح کوتاه

مارک‌داون را به دوره‌های ویدیویی جذاب تبدیل می‌کند. یک موتور پردازش Go محتوا را از طریق چندین ارائه‌دهنده LLM غنی می‌سازد، روایت (Bark/SpeechT5 TTS) و موسیقی تولید می‌کند و آن را برای پخش‌کننده‌های Electron دسکتاپ، React Native موبایل و React وب ارائه می‌دهد، با استقرار کامل Docker و نظارت.

## توضیح مفصل

تولید یک دوره ویدیویی معمولاً نیازمند کار یک استودیوی کوچک تولید است: نوشتن اسکریپت، ضبط روایت، تهیه موسیقی، ویرایش، کدگذاری و سپس ساخت پخش‌کننده برای هر پلتفرمی که مخاطبان ممکن است استفاده کنند. Courses-Creator کل این زنجیره را به یک ورودی — یک اسکریپت مارک‌داون — و یک دستور فشرده می‌کند. در مرکز آن یک پردازشگر هسته‌ای Go قرار دارد که یک خط لوله کامل ویدیو/صدا را اجرا می‌کند: محتوای نوشتاری را از طریق چندین ارائه‌دهنده LLM (OpenAI، Anthropic و Ollama محلی) غنی می‌سازد، روایت طبیعی را با موتورهای تبدیل متن به گفتار (Bark، SpeechT5) تولید می‌کند، موسیقی پس‌زمینه را اضافه می‌کند و قطعات را به دوره‌های ویدیویی نهایی مونتاژ می‌کند. وظیفه نویسنده در سطح ایده‌ها و کلمات باقی می‌ماند؛ سیستم صداگذاری، موسیقی‌گذاری و تولید را بر عهده می‌گیرد. و از آنجا که یک دوره تنها زمانی مفید است که مخاطبان بتوانند آن را تماشا کنند، ارائه آن به‌صورت چندسکویی طراحی شده است: یک اپلیکیشن سازنده Electron برای دسکتاپ، یک پخش‌کننده React Native برای موبایل و یک پخش‌کننده React برای وب، که همگی از یک سیستم REST API و پردازش پس‌زمینه تغذیه می‌شوند — یک بک‌اند، سه کلاینت درجه یک، بدون نیاز به پیاده‌سازی مجدد برای هر پلتفرم.

نکته مهم این است که این زیرساخت تولید است، نه یک دموی نمایشی. بک‌اند شامل پایداری PostgreSQL، پردازش پس‌زمینه برای رندرهای طولانی TTS/ویدیو که هرگز API را مسدود نمی‌کنند، پیاده‌سازی‌های سرور MCP برای ارتقای تقویت‌شده با ابزار، معیارهای Prometheus، احراز هویت JWT و یک پروکسی معکوس nginx است — و کل این مجموعه به‌عنوان یک استقرار Docker Compose با پروفایل‌های نظارتی Grafana/Prometheus عرضه می‌شود که می‌توانید آن را در یک مرحله راه‌اندازی کنید. AI یک لایه ارتقا است، نه یک وابستگی: هر ارائه‌دهنده LLM اختیاری است، بنابراین خط لوله حتی بدون کلیدهای API برای عملیات پایه کار می‌کند و با ارائه کلیدها، ارتقای پیشرفته فعال می‌شود. این تصمیم واحد، ابزار را هم برای یک علاقه‌مند که به‌صورت آفلاین روی لپ‌تاپ کار می‌کند و هم برای یک سازمانی که ارائه‌دهنده دلخواه خود را متصل می‌کند، مناسب می‌سازد — و کل خط لوله رسانه‌ای زیرین با تست‌های واحد، یکپارچه‌سازی و انتها به انتها پوشش داده شده است، نه اینکه صرفاً بر اعتماد متکی باشد.

## چرا آن را ساختیم

تولید دستی دوره‌های ویدیویی کند است: نوشتن، روایت، موسیقی‌گذاری و ویرایش هر کدام نیازمند تلاش و ابزارهای تخصصی هستند. Courses-Creator این فرآیند را به یک خط لوله مبتنی بر مارک‌داون فشرده می‌کند تا یک اسکریپت منبع واحد به یک دوره تولیدشده تبدیل شود، و AI جاهایی را پر می‌کند که در غیر این صورت انسان‌ها باید به‌صورت دستی انجام می‌دادند.

## چرا انقلابی است

این سیستم تولید دوره‌ها را از یک هنر تخصصی و چندابزاری به یک خط لولۀ نرم‌افزاری تکرارپذیر تبدیل می‌کند: تألیف، غنی‌سازی با AI، تولید روایت و موسیقی، و پخش چندسکویی، همگی در یک بستۀ قابل‌انتشار تجمیع شده‌اند. قابلیت تنزل کارآمد به حالت بدون کلید API، قدرت پنهان این سیستم است — همان پایگاه کد، هم برای خالق مستقل با بودجۀ محدود و هم برای یک شرکت با قرارداد ارائه‌دهندۀ ممتاز، بدون نیاز به بازنویسی چیزی در میان، قابل‌استفاده است.

## نوآوری‌ها

- خط لولۀ تبدیل مارک‌داون به ویدئو با قابلیت غنی‌سازی چندگانه و قابل‌تعویض (OpenAI/Anthropic/Ollama).
- تولید خودکار TTS (Bark، SpeechT5) و موسیقی پس‌زمینه.
- پیاده‌سازی سرورهای MCP درون موتور پردازش برای بهبود ابزارمحور.
- یک بک‌اند که سه کلاینت درجه‌یک را سرویس‌دهی می‌کند (دسکتاپ Electron، موبایل React Native، وب React).

## چالش‌ها و راه‌حل‌ها

- **پردازش سنگین رسانه:** با خط لولۀ Go به‌علاوۀ پردازش پس‌زمینه حل شده تا کارهای طولانی TTS/ویدئو، کلید API را مسدود نکنند.
- **AI اختیاری اما قدرتمند:** با اختیاری و قابل‌تعویض کردن ارائه‌دهندگان LLM و بازگشت کارآمد به قابلیت‌های پایه‌ای حل شده است.
- **تحویل چندسکویی:** با یک API مشترک REST و سه اپلیکیشن پخش‌کنندۀ اختصاصی حل شده است.
- **قابلیت عملیاتی:** با پروفایل‌های Docker Compose، Prometheus/Grafana و احراز هویت JWT داخلی حل شده است.

## پشته فناوری (چرایی و چگونگی)

- **Go** — موتور پردازش اصلی، API مشترک REST، اجراکنندۀ وظایف، خط لوله (بیش از ۹۷۲ هزار بایت، زبان غالب).
- **TypeScript / React** — پخش‌کنندۀ وب و رابط کاربری مشترک.
- **Electron** — اپلیکیشن خالق دسکتاپ.
- **React Native** — پخش‌کنندۀ موبایل.
- **PostgreSQL** — پایداری دوره/وظیفه.
- **ارائه‌دهندگان LLM (OpenAI، Anthropic، Ollama)** — بهبود محتوا.
- **TTS (Bark، SpeechT5)** — سنتز روایت.
- **سرورهای MCP** — یکپارچه‌سازی ابزار درون موتور.
- **Docker Compose + nginx** — استقرار تمام‌پشته و پروکسی معکوس.
- **Prometheus + Grafana** — نظارت.
