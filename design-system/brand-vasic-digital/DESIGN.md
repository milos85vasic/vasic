# Brand — Vasic Digital (company)

Portable brand contract for the `vasic.digital` company site.

- **Voice**: bold, modern, confident, high-tech — an AI-development company (the Helix product family).
- **Accent**: red `#dc3545` (light) / `#ff6b6b` (dark). Full ramp `--od-accent-50..900`.
- **Type**: display **Space Grotesk**, body **Inter**, mono **JetBrains Mono** (shared foundation with the personal brand; only the accent differs).
- **Signature devices**: monospace eyebrows, strong hero, product-card grid, stat tiles.
- **Themes**: light + dark, both mandatory.
- **Tokens/components**: see `vasic-digital.css` — canonical source. No ad-hoc CSS (§11.4.162).
