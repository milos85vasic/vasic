# Third-party notices - design-system fonts

Every font file shipped under `design-system/` is third-party software under its own licence. This file is the record the
gate `scripts/verify-font-licences.sh` enforces: **a shipped font file with no row here, a row whose licence file is missing
or does not carry the SIL Open Font License text, or a row whose sha256 no longer matches the file, fails the gate.**
Paths are relative to `design-system/`. Licence: SIL Open Font License 1.1 (OFL-1.1), which permits bundling, embedding and
redistribution of the unmodified or subset font files, provided the licence text and copyright notice travel with them.

## The Noto script subsets (Arabic, Devanagari, CJK)

Inter has no Arabic, Devanagari or CJK glyphs, so the 15-language console needs a shipped face for ar, fa, hi, zh, ja and ko.
The source is the open-source Noto family (SIL OFL 1.1) as packaged by Debian (`fonts-noto-core`, `fonts-noto-cjk`), subset to
woff2 by `fonts/tools/build_noto_subsets.py`. The faces are declared in `fonts/fonts.css` (generated block, `unicode-range`
per script, `font-display: swap`), and the families are named in the brand tokens `--od-font-script` / `--od-font-script-cjk`
(`brand-vasic-digital/vasic-digital.css`; the CJK order is per page language through `:root:lang()`). Cyrillic (ru sr be kk)
stays on Inter, which carries Cyrillic and Cyrillic-ext; the display stack now ends in Inter so a Cyrillic heading is no longer
drawn by an OS font.

Regenerate (re-runnable, byte-deterministic; `--check-only` rebuilds in a temp directory and fails on any drift):

```bash
python3 design-system/fonts/tools/build_noto_subsets.py --catalogue-dir ../job_seeker/internal/i18n/messages \
    --corpus zh=_content_zh --corpus ja=_content_ja --corpus ko=_content_ko --check-coverage
```

Glyph decision, [DEFAULT - adjustable]:

- Arabic (ar, fa) and Devanagari (hi): the whole script block set. Both are small (about 50 KB and 43 KB per weight); Persian
  letters (U+067E U+0686 U+0698 U+06AF U+06A9 U+06CC) and the Persian and Arabic-Indic digits are inside it; ZWNJ is kept.
  Weights 400 and 700.
- CJK (zh ja ko): too large to ship whole, so each language carries a FLOOR plus what the product actually says. FLOOR is a
  standards-derived common-character set, reproducible offline through the Python codecs: zh GB2312 level 1 (3755 hanzi) and
  symbols; ja hiragana, katakana, JIS X 0208 level 1 kanji (2965) and symbols; ko KS X 1001 syllables (2350), jamo and symbols.
  CORE is the characters of the language's `<lang>.json` catalogue plus the characters of the repository's own translated site
  content (`_content_<lang>`). Each CJK family is two faces with DISJOINT unicode-ranges, core and rest, so a page that stays
  inside the product vocabulary downloads only the small core file (measured in chromium: a core-only zh page fetched
  `noto-sans-sc-400-core.woff2` and not the rest file). CJK ships weight 400 only; the browser synthesises bold, which avoids
  doubling a payload of about 0.3 MB (core) to 1.1 MB (core + rest) per language.
- A character outside floor, catalogue and corpus is not in any shipped face and falls through the stack to the OS CJK font. The
  generator's `--check-coverage` fails when a catalogue character is in no shipped face, so this is detected, not silent.

[VERIFIED 2026-11-24] On this host the catalogues of ar fa hi zh ja ko are not in `job_seeker/internal/i18n/messages` yet
(only `en.json`), so core was derived from the site corpus alone. [OPEN: FONT-001] Re-run the command above when the translated
catalogues land: catalogue characters move into core, the notices and `fonts.css` regenerate, and the gate below stays green.
[ASSUMED] zh means Simplified Chinese (Noto Sans SC, GB2312); a Traditional-Chinese locale would need Noto Sans TC. [OPEN: FONT-002]
[OPEN: FONT-003] The floors are standards tiers, not a measured frequency ranking; a frequency-ranked floor would be smaller.

Licence texts: `fonts/noto/OFL.txt` (Arabic, Devanagari; copyright Google LLC) and `fonts/noto/OFL-CJK.txt` (CJK; copyright
Adobe, Google), each carrying the OFL 1.1 text copied from the Debian package's `/usr/share/doc/<package>/copyright`.
`fonts/noto/SOURCES.tsv` records for every shipped file the source font, its sha256, the Debian package and version, the font
version, the codepoint count, the byte size and the file's own sha256.

Gate: `bash scripts/verify-font-licences.sh` fails (exit 1) when a font file under `design-system/` has no row above, a row's
licence file is missing or has no OFL text, a row's sha256 no longer matches the file, or a row names a file that is gone;
`--prove-failure` runs seven mutations and a control.
