Animation & interaction module

Every effect below is driven by OpenDesign motion tokens (--od-dur-*, --od-ease-*) and animates only transform and opacity for smooth, compositor-friendly motion.

Reduced motion: this page fully respects prefers-reduced-motion: reduce. With it enabled, all reveals, staggers, bounces, blinks, hovers, the accordion height animation, view transitions and the Lottie accents are neutralized — content appears instantly in its final state, with no looping motion.

Animated Lottie accents

Three branded Lottie JSON accents rendered by a tiny self-hosted player. The player and JSON are fetched only when the accent scrolls into view, and each animation pauses when off-screen.
