# Brand — Milos Vasic (personal)

Portable brand contract for the `milosvasic.ru` personal portfolio & CV.

- **Voice**: precise, technical, editorial, trustworthy — a senior AI/software engineer.
- **Accent**: crimson `#a31e39` (light) / `#ec3b58` (dark). Full ramp `--od-accent-50..900`.
- **Type**: display **Space Grotesk**, body **Inter**, mono **JetBrains Mono** (self-hosted).
- **Signature devices**: monospace section eyebrows (`// section`), fluid type scale, generous spacing, subtle card elevation.
- **Themes**: light + dark, both mandatory (`data-theme` + `prefers-color-scheme`).
- **Tokens/components**: see `milosvasic.css` — the canonical, only source of colors/type/space/component styles for this brand. Never hand-write CSS outside these tokens (§11.4.162).
